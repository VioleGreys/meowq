# Meowq: Фронты — заметки для Claude

Мобильная глобальная стратегия о Второй мировой войне на Godot 4.3+ (GDScript).
Цели и этапы — в `ROADMAP.md`. Работаем поэтапно: этап заканчивается рабочей
сборкой, тестами и скриншотами; следующий этап начинаем только после «ок»
пользователя. Общение и тексты в игре — на русском.

## Состояние
- Этап 0 (фундамент) готов.
- Этап 1 (историческая карта Европы 1936 г.) сделан, ждёт «ок» пользователя.
  Экономика и армии стран пока временные (из численности городов) — это этап 2.
  ИИ на исторической карте войн не объявляет (`world.ai_wars = false`) до
  этапов 3/5.
- Решения пользователя — в `ROADMAP.md` («Принятые решения»).
- Известная проблема: день симуляции ~5–15 мс на 2500 провинциях, потоки пока
  не ускоряют тик — этап 7.

## Карта
- Собирается на ПК: `python3 tools/build_map.py --ne <папка с GeoJSON Natural Earth> [--preview out.png]`
  (нужны numpy, scipy, pillow; GeoJSON — из github.com/nvkelso/natural-earth-vector/geojson).
  Результат в `data/europe1936/` (map.json, provinces.png.bin, relief.png.bin) коммитится.
- Границы 1936 г.: таблицы `ADM0_TAG`, `ADM1_TAG` и многоугольники `OVERRIDES`
  в `tools/build_map.py`; названия городов 1936 г. — `CITY_1936`.
- Игра читает карту через `scripts/sim/map_loader.gd`. Процедурный мир
  (`map_gen.gd`) оставлен для тестов: `-- --procedural`.

## Ограничения по содержанию
Реальная история (страны, границы, лидеры, события, даты) — можно. Ассеты и
тексты коммерческих игр (графика, деревья фокусов, тексты событий, музыка,
название) — не копируем; всё оформление и тексты пишем сами.

## Проверка
Путь к Godot у пользователя может отличаться — уточнить и записать сюда.
- Перепарсить скрипты / обновить кэш классов: `godot --headless --editor --quit --path .`
- Тест детерминизма и скорости: `godot --headless --path . --script res://tests/sim_bench.gd`
  (`-- --large` — большая карта). Однопоточный и многопоточный результаты
  обязаны совпадать.
- Скриншот без человека: `godot --path . -- --screenshot=out.png --nation=GER --days=120`
  (доп. флаги: `--zoom=1.6 --select --tab=research --pick=1`).
  В облачном контейнере: `xvfb-run -a godot --rendering-driver opengl3 ...`.
После изменений: парсинг без ошибок, sim_bench проходит, скриншот посмотреть.

## Правила многопоточности (см. `scripts/sim/parallel.gd`)
- Параллельная фаза = «посчитать параллельно → применить в главном потоке по
  порядку». Задачи только читают мир и пишут в свой слот `results[i]`.
- Случайность в задачах — только `Parallel.rng(seed, day, index)`.
- Не читать из потоков константные `Array/Dictionary` скриптов (в 4.3 гонки и
  падения) — копировать таблицы в Packed-массивы мира.
- Массивы чужого объекта (`world.p_controller`) выносить в локальную
  переменную один раз на задачу; соседство — CSR (`adj_start/adj_list`).
- Мелкую работу не распараллеливать (порог `min_count`, запуск группы ~50 мкс).

## GDScript
- `:=` не выводит тип из нетипизированных значений (элементы `Array`, поля
  через нетипизированную переменную) — писать `var x: int = ...`.
