# Meowq: Фронты

Мобильная глобальная стратегия на Godot 4.3+ (GDScript): страны, провинции,
дивизии, фронты, промышленность, наука и капитуляции — со своим миром и своим
визуальным стилем. Симуляция и генерация карты используют все ядра телефона
через `WorkerThreadPool`.

## Запуск

1. Установите Godot **4.3** или новее.
2. Откройте папку проекта (`project.godot`) и нажмите F5.
3. На ПК мышь эмулирует касания; колесо мыши — масштаб.

Экспорт на Android: Editor → Manage Export Templates → установить шаблоны,
затем Project → Export → пресет «Android» (arm64-v8a, рендерер Mobile, альбомная
ориентация). Нужны Android SDK и debug keystore, как описано в документации Godot.

## Как играть

- **Выбор страны** — коснитесь страны на карте и нажмите «Начать игру».
- **Карта** — тяните одним пальцем, масштаб двумя пальцами.
- **Войска** — коснитесь провинции со своими фишками, затем провинции-цели.
  Если цель вражеская, начнётся бой. «Все войска» выделяет всю армию.
- **Время** — кнопки `II 1 2 3 4` (пауза и скорости).
- **Армия** — формирование дивизий (снаряжение + призывники, 14 дней).
- **Наука** — 16 технологий: атака, защита, организация, скорость, промышленность.
- **Стройка** — что строить: гражданские фабрики (стройка/наука) или военные
  заводы (снаряжение).
- **Дипломатия** — объявление войн. Страна капитулирует, потеряв большую часть
  очков победы (или столицу и почти половину очков).
- **Режим карты** — политическая / местность / промышленность.

Бой: каждый день атакующие и защитники наносят урон организации и силе.
Местность (лес, холмы, горы, города) даёт защитнику бонус и замедляет движение.
Части без организации отступают; без пути отступления — уничтожаются.

## Устройство

```
scripts/sim/      — симуляция, без зависимостей от сцены
  world.gd        — всё состояние мира (Packed-массивы по провинциям, страны, дивизии)
  map_gen.gd      — генерация: рельеф → провинции (Вороной с искажением) → соседство → страны
  simulation.gd   — дневной тик: экономика, ИИ, движение, бои, пополнение, капитуляции
  ai.gd           — план ИИ страны (только чтение мира)
  pathfinder.gd   — BFS по графу провинций
  parallel.gd     — обёртка над WorkerThreadPool
  tech.gd         — дерево технологий
scripts/view/     — карта (шейдер + камера + жесты), фишки, интерфейс
shaders/map.gdshader — отрисовка провинций по id-текстуре + палитре
tests/sim_bench.gd   — безголовый тест детерминизма и замер скорости
```

### Карта

Провинции хранятся как текстура id (RG8): каждый пиксель — номер провинции.
Шейдер берёт цвет из маленькой палитры (64×N) и сам рисует границы провинций,
стран, побережье, штриховку оккупации и рельеф с освещением. Смена владельца —
это обновление одного пикселя палитры, без перерисовки карты.

### Многопоточность

Каждая тяжёлая фаза устроена как «посчитать параллельно → применить в главном
потоке»: задачи только читают мир и пишут в свой слот массива результатов, а
изменения применяются последовательно в фиксированном порядке. Случайность
внутри задач — из ГСЧ, засеянного (seed, день, индекс). Поэтому результат
**одинаков при любом числе ядер** — это проверяет `tests/sim_bench.gd`.

Параллельно выполняются: генерация рельефа, назначение пикселей провинциям,
подсчёт центров/соседства, планирование ИИ всех стран, экономика (на больших
картах), движение и бои (когда их много).

Подводные камни GDScript, найденные при профилировании (см. `parallel.gd`):
- обращение `world.some_array` из чужого объекта копирует Variant и атомарно
  трогает общий счётчик ссылок — ядра начинают мешать друг другу, поэтому
  массивы выносятся в локальные переменные задачи, а соседство хранится плоско (CSR);
- константные `Array/Dictionary` скриптов, читаемые из потоков, в 4.3 давали
  гонки и падения — таблицы копируются в Packed-массивы мира;
- запуск группы задач стоит ~50 мкс, поэтому мелкие фазы идут в одном потоке
  (порог `min_count`).

Замеры в контейнере с 4 ядрами (`godot --headless --script res://tests/sim_bench.gd`):
генерация карты 1.9–2.2 с → 0.85–0.9 с (≈2.3×). Дневной тик занимает 1–4 мс
и при обычном размере карты почти не выигрывает от потоков — там работы
слишком мало; выигрыш растёт с размером карты и числом воюющих стран.

```
godot --headless --path . --script res://tests/sim_bench.gd            # обычная карта
godot --headless --path . --script res://tests/sim_bench.gd -- --large # большая
```

Скриншот без участия человека (удобно для CI):
`godot --path . -- --seed=4242 --screenshot=out.png --days=120`
