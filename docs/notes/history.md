  России (война с СССР), управление на Балканах, «Дуйсбург», война США, 8-я

- Правка деревьев — скриптом с записью в формате файла (фокус в две строки):
  писать через `json.dumps` по одному фокусу, как в файле, иначе дифф на весь файл.
- `scripts/sim/history.gd` —
  фокусы, события, эффекты, правила капитуляции (Виши, конец гражданской
  войны); данные — `data/world1936/focuses.json` (деревья GER/SOV/ITA/ENG/FRA +
  `_generic`), `events.json`, `areas.json` (исторические области по adm0/рамкам).
  «Спящие» государства (NSP, SLO, VIC) — `dormant` в nations.json. Дата в условии
  фокуса = «завершить не раньше». Фокусы — 35 или 70 дней, до 150 в крайнем
  случае (проверяет data_check); развилки — `exclusive` (исторический путь —
  первый в списке), `requires_any`; эффекты `later` (через N дней), `ships`,
  `ideology`, `leader`; условия `at_war`, `ideology`. ИИ (любой режим) идёт
  строго по исторической ветке (свои решения — исторические), но исторических
  гарантий у него нет: фокус создаёт событие, исход — бросок по состоянию
  мира, ответ ИИ-страны — тоже бросок; шанс виден на карточке фокуса до выбора
  (решение пользователя, `docs/design/events_germany.md`). Пока условий нет,
  `_ai_option` берёт исторический вариант — временно. Событие из эффекта
  (`event`) наступает на следующий день (`event_queue`: [id, кто, не раньше]).
  Событие игрока с выбором (`History.event_has_choice`: >1 варианта и нет
  `"guaranteed"`) — в `pending_events`, ход не останавливает: пауза при приходе
  (`main._ui_update`, `_event_seen`), срок `World.EVENT_ANSWER_DAYS`=14
  (`pending_since`, `History._answer_overdue`). Без выбора — применяется сразу,
  лист для прочтения (`info_events`, `world.event_front()`).
  Репутация, помощь, торговое влияние, шансы — `scripts/sim/relations.gd`
  (`World.rep` N×N, `aid`, `trade_bonus`; условия `Relations.cond`, шанс
  `Relations.chance`: без потолка, ≥100 % — гарантия, излишек — запас). У события `chance` —
  шанс исторического ответа ИИ (`History._ai_answer`), снимок условий на день
  фокуса (`event_snap`); эффекты `roll`, `rep`, `aid`, `trade`,
  `drop_guarantee`; прогноз на карточке фокуса — `History.forecast_text`.
  data_check проверяет условия шансов. ИИ готовит условия своих будущих
  событий (`History._ai_prepare`: план с начала партии, сверка после каждого
  фокуса, `prep_day`; таблица шансов — `world.chance_log`, печатает history_check):
  `prep_divs` → `AIPlanner.plan_economy`, гарантии, пакты, `improving`
  (улучшение отношений, и у игрока), помощь (`Relations.give_aid`).
  Общая шкала сил (нацизм, коммунизм, демократия, нейтралитет делят 100 %) —
  `Relations.update_threat` (каждый день, `world.threat`), агрессивность
  `Nation.aggression` + `Nation.diplo` (действия, тают 5 %/мес; уступки —
  эффект `concede`, дискредитация ≤12, тают 2 %/мес), потенциал ≤30, действия ≤70; условие `threat`; у шанса
  `"bloc": true` — надбавка 50·доля/(доля+30) (`Relations.bloc_of`).
  Исторический запас ≥15 % (history_check печатает шансы и шкалу). `History._ai_pick_historical`
  планирует по срокам: срок — у датированных
  фокусов с историческими эффектами (событие, война, договор…), считается запас
  до всех сроков сразу. Запись focuses.json — `tools/focus_json.py`. Дерево
  Германии (41 фокус) — образец полного дерева; по нему (логика жанра: ветки
  промышленность/наука, политика с историческими событиями и небывшими
  развилками для игрока, армия/флот/авиация) — СССР (34), Италия (28),
  Британия (27), Франция (21), США (22), Япония (17), Китай (12); у каждой из
  остальных стран — своё дерево (1–18 фокусов по размеру страны): свои заводы,
  программы, оружие и политика по истории (строение — как в жанре, содержание
  своё); `_generic` — только запас для стран без дерева. У каждой страны ≥20
  фокусов (всего ~1760); дополнительные пишутся в `tools/focus_extra/*.txt`
  (компактный формат) и вносятся `python3 tools/focus_add.py <файлы>` —
  он сам ставит фокус в ветку (i/p/m) и цепляет к нижнему фокусу колонки.
  ИИ проверяет фокусы, только когда закончил предыдущий; если взять нечего —
  ждёт до даты ближайшего (`focus_wait_until`), раньше будит изменение мира
  (`World.focus_epoch`: войны, мир, союзы, флаги, строй), не реже раза в 30
  дней. Фокусы по id — индекс `world.focus_index`; даты — кэш `World.day_of`. В исторической
  игре ИИ не вступает во фракции по идеологии (`Diplomacy.ai_turn`) — союзы
  только фокусами и событиями. Вступление Румынии, Венгрии, Финляндии в войну
  с СССР — авто-события `rom_east`/`hun_east`/`fin_continuation`. Порог
  капитуляции — `capitulate_at` в nations.json (по умолчанию 0,3; Китай 0,1,
  СССР 0,15); провинции у союзника по стороне не считаются потерянными. Ключевые (датированные) фокусы — с эффектами
  событий, войн, договоров, лидера, репутации (`History._is_key`); условие
  доступности `dead` (страны больше нет). «22 июня» (`sov_patriotic`) —
  авто-событие по `at_war_pair`. `world.historical` (переключатель на экране
  выбора): ИИ идёт по фокусам в порядке списка, без случайной агрессии,
  гарантий и наступательных призывов союзников. Капитуляция — при <30% очков
  победы; потеря столицы — переезд правительства. ИИ окапывается, держит
  гарнизон в столице, осторожность наступления по идеологии.
  Тексты фокусов и событий — свои, по истории.
  Данные — `data/world1936/nations.json` (идеология, лидер, население,
  фабрики, дивизии, колониальное население, флаг); раскладка по провинциям —
  `MapLoader._distribute_economy/_spawn_armies`; флаги — `scripts/view/flag.gd`.
  Цифры — собственные оценки по истории, не значения из чужих игр.

## Заметки пользователя на возвращение к фокусам (ноябрь 2026, ещё не сделано)
- Слоты науки прибавляются от фокусов, а не от фабрик. Сейчас третий слот у
  средних стран даёт правило по фабрикам (`Tech.slots_for`, ≥14 фабрик) —
  заменить: великие державы 3, остальные 2, сверху — эффект фокуса «+1 слот»
  (поле `research_slots` страны).
- Национализация территорий: от фокусов зависит, какие территории страна
  может национализировать. На ненационализированных — штраф ко всем
  ресурсам (добыче); национализация его снимает. Механики «своих» земель пока
  нет — продумать вместе с фокусами.
