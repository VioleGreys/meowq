# План оптимизации всей игры (ноябрь 2026, решение пользователя: делать по нему)

Цель — меньше фризов на телефоне (Realme RMX3472, Snapdragon 695, Adreno 619)
без ухудшения графики и без смены результатов (подписи `sim_bench`,
`perf_bench`, `save_check` — те же; C++ и GDScript — до бита).
Замеры: стенд нагрузки (`engine.md` «Стенд нагрузки»), цена частей карты
(`ui.md` «Цена частей карты»). После каждого шага — тот же замер «до/после»,
итог дописывать в строку шага.

## Исходные замеры (контейнер, 4 ядра Xeon, C++; телефон по ЦП ~×3)
- Тик: 40–57 мс (95 % — 60–105, пики 117): ИИ 25–43, флот + бои флота 20–31,
  экономика 13–33 (дни торговли раз в 14 дней), дипломатия до 34 (дни войн),
  оккупация до 17, снабжение 5–24. Телефон ~150 мс → скорость 5 (8 дн/с)
  на грани.
- Главный поток на скорости 5, мс за секунду: рисование фишек 180, буфер кадра
  33, интерфейс 33, верхняя строка 12; список фишек 7–18 мс за день.
- Действия: сохранение вручную 250–370 мс; окно «Армия» 67 (1936 г. — 244),
  «Флот» 38, «Страны» 33, «Дипломатия» 29, «Наука» 27; режим карты 25–54.
- Карта (llvmpipe, полный кадр живой / из заготовок): ×1 — 155 / 90 мс,
  ×3 — 347 / 122, ×5 — 368 / 136. Вблизи треть живого кадра — постройки и
  деревья (модели), затем рельеф (art), дороги, реки. При сдвиге шейдер почти
  не работает (кэш движения); дорого — полная перерисовка.
- Вес APK: заготовки ~270 МБ, графика карты 51, данные мира 30.

## Шаги (по пользе; [ ] — не сделано)
### А. Фризы главного потока (интерфейс)
1. [x] Сохранение вручную — в поток симуляции: `main.save_game_bg(имя, название, done)`
   ставит заказ в `_save_reqs` и будит поток своим `sim_sem.post()` (день при этом
   не считается); `done(err)` — в главном потоке (`call_deferred`). В кадре
   250–370 мс → 0; фоном ~250 мс (снимок мира `encode` ~165 мс — под замком,
   var_to_bytes ~46, zstd ~20). Без фонового потока — сразу, как раньше.
2. [x] Фишки: главная цена была не в фишках, а в ~1800 знаках городов (2/3
   перерисовки: перебор с отсевом по масштабу и краю экрана, рисуется ~50).
   Подписи стран и города — свой холст `StaticMarks` под слоем
   (`show_behind_parent`, общий шейдер переноса): перерисовка — при сдвиге
   камеры за запас или новой версии подписей и городов (версию считает `build`
   в потоке симуляции по виду города и признаку «стоят войска»). Отсев: сетка
   мест `_cgrid` (клетка 256), ранний выход по масштабу (города по убыванию
   очков, столицы — первым проходом), кэш ширины подписей, кольца мест флотов
   `_place` — один раз. Скриншоты 0.9/1.6/2.6 — попиксельно те же.
   Фишки + города: 180 → ~83 мс/с; одна перерисовка фишек ~3–5 мс (флоты ~1.5).
   Дальше (если надо): MultiMesh плашек, `_place` флотов по сетке.
   Отложено (решение пользователя, ноябрь 2026): подписи городов — заранее в
   атлас картинок (каждое имя один раз, 2 размера, с обводкой), рисовать одной
   командой вместо `draw_string_outline` + `draw_string`; вид и правила те же.
   Ожидание — слой городов в 2–4 раза дешевле (сейчас ~2–2.5 мс за перерисовку,
   ~25 мс/с при движении на ПК). Впекать подписи в заготовки карты — нет:
   размер плавал бы между шагами, подписи стран переезжают с границами, города
   сдвигаются от фишек и уступают место, наклон перекосил бы текст (`ui.md`).
3. [x] Верхняя строка: надписи, значки и раскладка — только по новому снимку
   (`is_same(top_data, _top_shown)`), кнопки скорости — при смене; фазы — только
   при видимой строке замеров. Буфер кадра 40 → 17 мс/с, главный поток (main)
   76 → 48 мс/с.
4. [x] Окна: сборка вне дерева и сверка со стоящим окном (`UiPatch`, `ui.md`
   «Окна: сборка вне дерева и сверка»). Дорог вход узла в дерево (~0,3 мс на
   подпись), а не расчёты. Совпавшие узлы остаются, меняются отличия. Своё тело
   у каждого окна и страницы; главные окна заготавливаются в простое. Стенд:
   «Армия» 58 → 22–25 мс, «Флот» 29 → 10–12, «Производство» 16 → 7–8,
   «Дипломатия» 44 → 21–29; пересборка после нажатия — так же дешевле.
   Скриншоты окон попиксельно те же. Проверка — `--patchtest` (700 сверок,
   0 расхождений).
   Не сделано (пока не нужно): видимая часть длинных списков («Страны»
   ~18 мс, «Загрузка» ~20 — там ещё чтение файлов); оболочка окна (анимация,
   лист) ~5 мс на кадр, пока окно открыто.
5. [x] Режимы карты: кэш по дню не понадобился — дорогими были кайма границ
   (пересчёт при каждой смене режима, ~15 мс, хотя зависит только от
   контролёров) и проход по провинциям через `set_pixel` (10–20 мс). Теперь —
   цвета в целочисленный массив и одним `set_data`, кайма — только при новых
   контролёрах, перекраска и частичная перерисовка по изменившимся провинциям
   в любом режиме (`ui.md` «Палитра режимов»). Стенд: режим карты 27–33 →
   1,7–4,9 мс, палитра 11,2 / 41 → 1,6 / 3,7 мс за секунду. Цвета до бита те же.
   Кадр смены режима — полная перерисовка карты (ГП), её не избежать.

### Б. Тик симуляции (точно, подпись та же)
6. [x] Флот и бои флота. Сами бои ~0,5 мс, ядро для них не нужно. Цена
   фазы — хвост GDScript (~70 нс на операцию) по конвоям, пунктам и ИИ.
   Решение пользователя — конвои и пункты в C++ («meowq-core 67», двойники
   GDScript, до бита; сверка `tests/kernel_check.gd` — 0 расхождений):
   `convoy_danger` (опасность всех пар страна-бассейн сразу — бассейны делят
   зоны, `forces.md`), `convoy_day` (проход путей стран), `contracts_sig`
   (подпись 643 договоров), `depots_scan` (разбор пунктов, `supply.md`).
   GDScript: кэш участков суши, `ai_ports` вне хода — без прохода портов, ИИ
   флота — силы противника списком на день и `trade_zones` по постоянному
   списку прибрежных городов (раньше раз в 30 дней на страну — все
   провинции: ~2/3 цены ИИ флота). Стенд `tests/fleet_bench.gd` (одна партия
   01.07.1941, 30 дней, до / после): фаза «флот» 11,0–11,7 → 7,2–7,7 мс,
   «флот:бои» 6,2–6,7 → 4,0–4,3, торговля 4,9–5,3 → 2,9–3,1, пункты 2,5–2,7 →
   1,5, ИИ флота 1,8–2,0 → 0,8. Подписи perf_bench (C++ и без), sim_bench,
   save_check — те же. Осталось в фазе: ИИ авиации ~1,4, высадки ~1,
   участки суши (C++) ~0,4, проход стран у пунктов ~0,7.
   Старое, не от шага: `forces_check` падает на «план высадки из Эмден в
   Шпицберген 2» (и до шага 6).
