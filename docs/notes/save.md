# Главное меню, сохранение и загрузка

Заметки для Claude (вынесены из `CLAUDE.md`; указатель — там). Дополнять здесь.

- Главное меню и сохранения (этап 8, сделано, ждёт «ок»): `scripts/sim/save.gd`
  (`SaveGame`). Состояние мира пишется целиком БЕЗ ручного списка полей: все
  переменные `World` и его объектов (страны, дивизии, флоты, армии, планы
  высадок…) обходятся по списку свойств — новое поле мира попадает в сохранение
  само. Не пишутся (`SKIP_WORLD`): картинки карты и неизменяемые описания из
  файлов игры (`focus_trees`, `focus_index`, `event_defs`, `areas`,
  `spirit_defs`) — при загрузке мир сначала собирается `MapLoader`, сверху
  кладётся сохранённое; `Simulation.new(world, false)` — без стартовых
  пересчётов (они изменили бы состояние). Поэтому: описания фокусов/событий в
  ходе партии НЕ менять на месте (иначе добавить их в сохранение); новый
  внутренний класс мира — дописать в `SaveGame._classes`; состояние симуляции
  вне мира (`sim.land_totals`) — в `encode/decode`. У дивизии пишутся только
  собственные поля (`DIV_FIELDS`), числа — в массивах `d_*`. Файл
  `user://saves/<имя>.mqs`: заголовок (страна, дата, вид камеры — читается без
  распаковки) + zstd; запись через временный файл; отпечаток карты
  (`fingerprint`) не даёт загрузить сохранение от другой карты. ~0,35 МБ,
  запись/чтение 55–85 мс на ПК. Проверка — `tests/save_check.gd`: партия после
  загрузки через N дней обязана совпасть с непрерывной ПО ВСЕМУ состоянию
  (сравнение `SaveGame.encode`, печатает различающиеся поля) — так же удобно
  искать любую недетерминированность. `main.gd`: состояние `menu` (после
  загрузки мира; инструменты `--screenshot/--bench_rt` — сразу `select`),
  `new_game`, `to_menu`, `save_game`, `load_game`, `world_fresh`;
  автосохранение (`Settings.autosave`, одна запись `auto`): раз в 5 минут игры
  не на паузе — из потока симуляции сразу после дня (экран не замирает), при
  выходе в меню, сворачивании и закрытии (`NOTIFICATION_APPLICATION_PAUSED`).
  Вид камеры для потока симуляции — копия в `_cam_*` (узлы сцены из потока не
  трогать). Интерфейс: `Hud.show_menu` (лист поверх карты мира), корешок
  «Меню» вместо «Настроек» (11-й корешок на экран не помещается) — папка со
  страницами `menu/save/load/settings` (`MENU_TABS`); опасные действия
  (перезапись, удаление, загрузка поверх партии) — вторым нажатием
  (`_confirm`). «Назад» на Android на пустом экране открывает меню партии.
  Скриншоты: `--menu=main|load|settings`, `--save=имя`, `--load=имя`.
  Корешок: `python3 tools/build_ui.py --spine menu`.
  Известное: лист «Настроек» шире экрана 1280 (ряды кнопок) — было и раньше.
